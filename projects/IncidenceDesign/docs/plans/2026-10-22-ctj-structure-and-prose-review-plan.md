## Hard constraints

- **Word limit.** The body limit is 3,500 words (Clinical Trials). It counts prose and
  heading words and excludes the abstract, declarations, references and exhibits; see
  `submission_checklist.md` for the counting method (texcount). The last count was
  3,362 on 2026-10-14, plus about 40 words added on 2026-10-21 and not yet recounted.
  **Recount first.** Every new heading costs words, so each structural proposal must
  give its net word change and say where the words come from.
- Abstract limit is 425 words (now 394). Six main exhibits (two tables, four figures).
- This is a co-authored paper (Walther, Habib, Simpson, Lin). Structural changes need
  the same coauthor sign-off as any other change; flag anything that changes a claim.
- No invented numbers. Every number traces to `results/` in this project.
- Never change citations, `\ref`/`\label`, math or numbers in a prose edit.
  `apply_edits.py` (in the bios-dissertation review folder) checks Quarto syntax only:
  before using it on this file, add a LaTeX mode that also compares `\cite{...}` keys,
  `\ref{...}`/`\label{...}` and `\(...\)`/`\[...\]` math, and test it on a synthetic
  case that changes each one.
- Cut material goes to `paper/thesis_chapter/notes/trimmed-material.md` (or a CTJ
  side file), with date and reason. Never delete it.

## Part A: structural review (one session or subagent)

Current outline (2026-10-22): Introduction (no subsections); Methods: Simulation study on
a 100-cluster grid / Estimating treatment effect and allocation risk / North Carolina
sudden unexpected death application; Results: two subsections (simulation; NC
application); Discussion: Implications / Limitations / Continued work / Conclusions.

Answer Andrew's three questions, each with a concrete proposal, its net word cost and
how other CTJ / Sage Clinical Trials papers handle it (look at 3–5 recent design or
simulation papers in the journal):

1. **Introduction subsections.** Would headings such as Background, Aims or contribution,
   and Outline help? Note that short journal introductions often run without them, and
   that headings cost words against the limit. If headings are not worth it, say whether
   the same effect can come from paragraph order and a closing aims paragraph.
2. **Methods order.** Methods opens with "Simulation study on a 100-cluster grid" before
   stating the model. Propose an order that sets out the setup first: estimand and
   outcome model, spillover model, the designs compared, the estimator and metrics,
   then the simulation study and then the application. Say what moves from where, and
   whether some setup belongs in the supplement given the word limit.
3. **Results subheadings.** Results run 3–4 pages with two subsections. Propose
   informative subheadings that follow the order of the exhibits and the aims, e.g.
   overall design ranking, dependence on the spillover regime, allocation risk,
   sensitivity, then the NC application. Check that each subheading has enough text
   under it to justify itself.

Also check: the Discussion order, signposting between Methods and Results (the same
order in both), and whether each exhibit is introduced where the text first needs it.

Output: `paper/ctj_manuscript/review/ctj-structure.md`: current outline with word counts,
diagnosis, each proposal (operation, reason, net words, labels affected, Recommended or
Optional), proposed outline side by side with the current one, and considered and
rejected.

## Part B: prose review (after Andrew decides on Part A)

Run the `human-writer` skill as in Gate 1 of the dissertation plan: write
`paper/ctj_manuscript/review/ctj-edits.md` in the same edit-list format (verbatim
**Before**, occurring exactly once). Where the accepted Chapter 3 edits apply to text the
manuscript shares, reuse them and cite their IDs. Then run the Gate 1b independent
review: apply all edits to a copy, run the invariant check (LaTeX mode) and
`repeated_openers.py`, and have a fresh subagent read the edited manuscript start to
finish and write `ctj-review.md`. Andrew does not want runs of sentences or paragraphs
that open the same way.
