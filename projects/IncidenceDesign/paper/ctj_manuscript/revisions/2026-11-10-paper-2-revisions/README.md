Open `feedback.html` in a browser. It is self-contained and needs no server or
build command. Links to the PDF and JSON expect those files to remain beside it.
Embedded passage images remain available if the HTML is shared by itself.

Use FCL-001 through FCL-060 to refer to existing annotations. Additional notes can
name an ID or specify a quoted passage, page and section, or be marked as general
feedback. Notes typed into the page save only in that browser's local storage,
which some browsers restrict for local files. The page reports storage failures.
**Export your notes** downloads a JSON backup that can be shared for planning.
The HTML file itself does not acquire those notes. There is no import control;
an exported file can be supplied with the next revision-planning request.

Page numbers refer to the annotated nine-page reading preview, not the submission
layout or thesis chapter. IDs follow annotation order within each page, which may
differ from reading order. The 58 highlights carry written comments; the two
strikeouts have no comment text. Empty popup objects and document links are not
additional comments. Each original passage image includes surrounding text so
short or imperfectly extracted selections can be checked.

The PDF predates the current three-decimal rule. The author confirmed that rule
was adopted after the draft was sent for review. FCL-050 therefore has its
precision request recorded as addressed, with the separate pooled-result/Table 2
question still open. Arrow responses contained in the current PDF are retained
verbatim without assigning authorship to those additions.

Chapter 3 destinations are provisional topic matches, not verified line-level
locations or approved revisions. Neither manuscript has been changed by creating
this register. Additional notes and the revision plan remain open.
